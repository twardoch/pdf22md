# Task 8.3: Example Scripts

## Problem

Users need practical examples for common workflows.

## Acceptance Criteria

- [ ] Batch conversion script
- [ ] OCR workflow script
- [ ] AI correction script
- [ ] Integration examples (Python, Node.js)
- [ ] Each script documented

## Scripts to Create

### examples/batch-convert.sh
Convert all PDFs in a directory to Markdown.

### examples/ocr-workflow.sh
Process scanned documents with OCR and AI correction.

### examples/watch-folder.sh
Watch folder for new PDFs and convert automatically.

### examples/python-integration.py
Call pdf22md from Python using subprocess.

### examples/node-integration.js
Call pdf22md from Node.js using child_process.

## Verification

Each script runs successfully with test data.
